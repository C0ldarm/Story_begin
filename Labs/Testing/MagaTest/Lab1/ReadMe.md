# Список зауважень

1. **Відсутність перевірки нерівності трикутника:** Немає перевірки умови $a + b > c$, $a + c > b$, $b + c > a$, що дозволяє створювати неможливі фігури та викликає $NaN$ у формулі Герона.
2. **Відсутність валідації додатності сторін:** Код дозволяє передачу від'ємних значень або нуля.
3. **Неточне порівняння типів `double`:** Пряме порівняння через `==` або `!=` замість використання похибки `EPSILON` призводить до помилок обчислення.
4. **Мутабельність та ризик некоректного стану:** Наявність окремих сеттерів дозволяє переводити об'єкт у некоректний стан, тому клас має бути `Immutable`.
5. **Порушення інкапсуляції:** Поля класу повинні мати модифікатори доступу `private final`.
6. **Відсутність перевизначення `equals()`:** Порівняння об'єктів відбувається за посиланням, а не за значенням сторін.
7. **Відсутність перевизначення `hashCode()`:** Унеможливлює коректну роботу об'єктів у хеш-колекціях.
8. **Відсутність `toString()`:** Ускладнює логування, налагодження та вивід об'єкта.
9. **Неінформативні назви змінних та відсутність Javadoc:** Рекомендовано змінити назви полів на `sideA`, `sideB`, `sideC` та задокументувати публічний API.
10. **Відсутність константи для похибки:** Значення допуску похибки для `double` не винесене в окрему константу.
